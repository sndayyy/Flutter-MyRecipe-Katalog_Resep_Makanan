# 🍽️ Recipe Catalog App

Aplikasi katalog resep sederhana menggunakan Flutter + Riverpod dengan fitur:
- Tambah resep
- Lihat detail resep
- Filter kategori
- UI clean & modern

*Projek ini dibuat untuk memenuhi tugas UTS pada mata kuliah Pemrograman Mobile 2
